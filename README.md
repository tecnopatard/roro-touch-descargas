# Descargas de Roro Touch

Página para instalar Roro Touch (Lesky Estudio) en las Macs del estudio:
https://tecnopatard.github.io/roro-touch-descargas/

- `index.html`: la página (GitHub Pages). Lee la última versión de Releases.
- `publicar.sh`: arma el instalador desde `main` de Roro Touch y lo publica como versión nueva.

El código de la app vive en un repo privado. Aquí solo van la página y los instaladores.
